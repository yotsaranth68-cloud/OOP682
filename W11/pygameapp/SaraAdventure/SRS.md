# เอกสารข้อกำหนดซอฟต์แวร์ (Software Requirement Specification) – เกม "Sarah ผจญภัย"

## 1. บทนำ
- **ชื่อเกม**: Sarah ผจญภัย
- **ประเภท**: เกมผจญภัย 2 มิติ (2D Adventure) ที่พัฒนาโดยใช้ Pygame
- **เป้าหมาย**: ผู้เล่นสวมบทบาทเป็น Sarah เพื่อสำรวจสองแผนที่, ผ่านพอร์ทัล, เก็บถ้วยรางวัลและจบเกมด้วยข้อความแสดงความยินดี

## 2. ขอบเขตของระบบ
- ระบบจะประกอบด้วย **สองแผนที่** (`Map 1` และ `Map 2`) แต่ละแผนที่มีขนาด **20 x 20 tiles**
- `Map 1` ใช้ **tileset ชื่อ "forest"**
- `Map 2` ใช้ **tileset ชื่อ "space"**
- ผู้เล่นเริ่มต้นที่ตำแหน่งเริ่มต้นบน `Map 1`
- มี **พอร์ทัล** ที่เชื่อมต่อจาก `Map 1` ไปยัง `Map 2`
- `Map 2` มี **ถ้วยรางวัล** (reward cup) ที่ผู้เล่นต้องเก็บ
- เมื่อเก็บถ้วยสำเร็จ, จะแสดง **ข้อความแสดงความยินดี** และเกมจบ

## 3. คำจำกัดความของคำศัพท์
| คำ | ความหมาย |
|---|---|
| **Tile** | หน่วยพื้นฐานของแผนที่ที่แสดงกราฟิก (เช่นพื้นดิน, ต้นไม้) |
| **Tileset** | ชุดของกราฟิกที่ใช้สร้างแผนที่ (เช่น forest, space) |
| **Portal** | จุดเชื่อมต่อระหว่างแผนที่สองแผนที่ |
| **Reward Cup** | ไอเท็มที่ต้องเก็บเพื่อจบเกม |
| **Congratulations Screen** | หน้าจอแสดงข้อความยินดีเมื่อผู้เล่นสำเร็จภารกิจ |

## 4. ความต้องการเชิงฟังก์ชัน
1. **การแสดงแผนที่**
   - ระบบต้องโหลดและแสดง `Map 1` ด้วย tileset `forest` ขนาด 20x20 tiles
   - ระบบต้องโหลดและแสดง `Map 2` ด้วย tileset `space` ขนาด 20x20 tiles
2. **การเคลื่อนที่ของ Sarah**
   - ผู้เล่นสามารถเคลื่อนที่ในสี่ทิศ (ขึ้น, ลง, ซ้าย, ขวา) ภายในขอบเขตของแผนที่
   - การเคลื่อนที่ต้องตรวจสอบการชนกับสิ่งกีดขวาง (เช่น ต้นไม้, กำแพง) ของ tileset
3. **พอร์ทัล**
   - พอร์ทัลอยู่บน `Map 1` ที่ตำแหน่งกำหนด
   - เมื่อ Sarah ยืนอยู่บนพอร์ทัลและกดปุ่ม (หรืออัตโนมัติ) จะเปลี่ยนฉากไปยัง `Map 2`
4. **ถ้วยรางวัล**
   - ถ้วยอยู่บน `Map 2` ที่ตำแหน่งกำหนด
   - เมื่อ Sarah ถึงตำแหน่งถ้วยและทำการเก็บ (เช่น กดปุ่ม) ระบบบันทึกสถานะว่าได้รับรางวัล
5. **จบเกม**
   - หลังจากเก็บถ้วยสำเร็จ ระบบแสดงหน้าจอ **Congratulations** พร้อมข้อความ "ยินดีด้วย! คุณได้เก็บถ้วยรางวัลแล้ว" และหยุดการเล่น
6. **การบันทึกสถานะเกม**
   - ระบบต้องบันทึกสถานะปัจจุบัน (แผนที่ที่อยู่, ตำแหน่ง Sarah, การเก็บถ้วย) เพื่อให้สามารถโหลดต่อได้ (optional) 

## 5. ความต้องการเชิงไม่ใช่ฟังก์ชัน
- **ประสิทธิภาพ**: เกมต้องทำงานที่ 30 FPS ขึ้นไปบนเครื่อง Windows 10/11 ที่มี GPU พื้นฐาน
- **ความเข้ากันได้**: รองรับ Python 3.10+ และ Pygame 2.5.x
- **ความเสถียร**: ไม่มีการค้างหรือ crash ในระหว่างการเปลี่ยนแผนที่หรือการเก็บถ้วย
- **การออกแบบ UI**: ใช้สีสันและกราฟิกที่สอดคล้องกับธีม forest และ space เพื่อให้ผู้เล่นรับรู้ความแตกต่างของสองแผนที่
- **การทดสอบ**: มี unit test ตรวจสอบการเปลี่ยนแผนที่และการเก็บถ้วยอย่างน้อย 5 กรณี

## 6. ข้อจำกัดและสมมติฐาน
- ผู้เล่นจะต้องใช้คีย์บอร์ด (WASD หรือ Arrow keys) สำหรับการเคลื่อนที่
- เกมจะไม่มีระบบเซฟ/โหลดขั้นสูง ยกเว้นการบันทึกสถานะพื้นฐาน (optional)
- ไฟล์ assets (tileset, sprite) จะอยู่ในโฟลเดอร์ `assets/` ของโปรเจค

## 7. การตรวจสอบและยืนยันความต้องการ
- **การทดสอบการเคลื่อนที่**: ตรวจสอบว่า Sarah ไม่สามารถออกนอกขอบเขต 20x20 tiles ได้
- **การทดสอบพอร์ทัล**: ตรวจสอบว่าการกดพอร์ทัลเปลี่ยนฉากจาก `Map 1` ไป `Map 2`
- **การทดสอบถ้วยรางวัล**: ตรวจสอบว่าการเก็บถ้วยทำให้แสดงข้อความยินดีและหยุดเกม
- **การทดสอบประสิทธิภาพ**: ตรวจสอบ FPS อย่างน้อย 30 FPS บนเครื่องทดสอบมาตรฐาน
